Credit-Debit Analytics Using SQL

 Project Overview
This project uses SQL to analyze credit and debit transaction data, understand transaction activity, and derive meaningful insights from banking records.

 Objectives
- Analyze credit and debit transactions.
- Compare transaction amounts and volumes.
- Calculate key transaction metrics.
- Identify transaction patterns and trends.
- Summarize banking activity using SQL queries.

 Tools and Technologies
- MySQL
- SQL
- SELECT and WHERE
- Aggregate Functions
- GROUP BY and HAVING
- Joins and Subqueries, where applicable
- CTEs and Window Functions, where applicable

 Skills Demonstrated
- SQL Query Writing
- Transaction Data Analysis
- Data Aggregation
- KPI Calculation
- Financial Data Analysis

 How to Run
1. Download the SQL script from this repository.
2. Open MySQL Workbench.
3. Create or select the required database.
4. Execute the SQL script.
5. Review the query outputs and insights.
